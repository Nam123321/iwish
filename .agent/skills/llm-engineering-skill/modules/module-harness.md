# Module: Harness & Evaluation Engineering

## Purpose
Establishes the foundation for deterministic evaluation and sandboxed execution. Transitions from ad-hoc Prompting to automated Evaluation Harnesses.

## Core Principles
1. Evaluation-Driven Development (EDD) is mandatory.
2. The Test Harness is the single source of truth for prompt effectiveness.
3. Decouple prompt logic from application code.
4. Separate the Evaluator LLM from the Generator LLM (LLM-as-a-Judge).
5. Continuous Regression Testing of prompts against golden datasets.

## Mental Models & Frameworks
- **The Harness Trinity**: Dataset (Golden pairs), Engine (Execution environment), Scorer (LLM-as-a-Judge / Heuristics).
- **Evaluation Taxonomy**: Deterministic (Regex/JSON), LLM-as-a-Judge (Rubric-based), Human-in-the-Loop (ELO Ranking).
- **Prompt Versioning Matrix**: Git-backed, semver-tagged prompts linked to specific model hashes.

## Decision Trees
- If output is strict JSON -> Use Deterministic Schema Validation.
- If output is creative/prose -> Use LLM-as-a-Judge with strict rubrics.
- If failure rate > 10% -> Add few-shot examples to the prompt.
- If model is changed -> Re-run full test harness suite.
- If context window expands -> Measure precision drop (Lost-in-the-Middle check).

## Anti-patterns
````text
[Anti-Pattern] Manual Vibe Checking
- Consequence: Unnoticed regressions and brittle behavior in production.
- Solution: Automated Harness with Golden Datasets.

[Anti-Pattern] Prompt in App Code
- Consequence: Deployment required for prompt tweaks; difficult to A/B test.
- Solution: Decouple prompts into external JSON/YAML or CMS.

[Anti-Pattern] Self-Evaluating Models
- Consequence: Sycophancy and bias towards its own output.
- Solution: Separate Evaluator model (e.g., GPT-4 scores Claude 3, or distinct API instances).
````

## Reusable Patterns
````text
[Pattern] LLM_As_A_Judge_Prompt
Standardized rubric prompt for scoring output quality (1-5 scale).

[Pattern] SandboxExecutionEnvironment
Isolated Docker/WASM container for testing code generated by LLM.

[Pattern] EvaluationDatasetSchema
JSON Lines format for input-output golden pairs.
````
