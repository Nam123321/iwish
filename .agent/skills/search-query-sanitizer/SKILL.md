# search-query-sanitizer

## Description
An agent skill that parses hybrid search queries to enforce bounded vector sizes, prevent unsafe string interpolation, and mask PII prior to indexing.

## Usage
Trigger this skill whenever a query is passed to the vector search engine to ensure compliance with telemetry, safe limits, and privacy standards.
