# process_mining_pm4py

## Purpose
Analyzes workflow event logs using `pm4py` to discover, monitor, and optimize dynamic processes. Provides process discovery, conformance checking, and bottleneck analysis from XES or CSV event logs.

## Prerequisites
- Python environment with `pm4py` and `pandas` installed.

## Usage
Use this skill when a user provides event logs (XES or CSV format) and wants to:
- Discover the underlying process model.
- Check if real executions conform to an expected model.
- Identify bottlenecks or deviations in workflow execution.
