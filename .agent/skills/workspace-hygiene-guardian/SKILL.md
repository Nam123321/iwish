# Workspace Hygiene Guardian (`/workspace-hygiene` | `/workspace-janitor`)

A Zero-Trust filesystem janitor engine designed to guarantee that project workspaces remain clean, organized, and free from loose scripts, temporary logs, diff dumps, and misplaced artifacts.

---

## 🛡️ Core Rules & Invariants

1. **Zero-Loss Collision Guard:**
   - Files are never deleted blindly.
   - When moving files to target folders, if a destination file already exists with different contents, the incoming file is preserved with an entropy timestamp (`filename_PID_TIMESTAMP.ext`).
2. **Zero-Root Invariant:**
   - No `.log`, `.diff`, `.err`, `.txt` dumps or ad-hoc `patch*.sh` / `fix*.py` scripts may reside in the project root.
   - All transient scratch files MUST reside in `_iwish-output/adhoc-workspace/scratch/`.
3. **Canonical 4-Level SSOT Invariant:**
   - Artifacts generated by workflows (reviews, debate transcripts, evidence, risk matrices) must be routed to their respective canonical directories in `_iwish-output/`.

---

## ⚡ Execution

Run the deterministic janitor script:
```bash
# Preview changes without modifying disk:
python3 .agent/scripts/workspace-janitor.py --dry-run

# Execute full zero-loss cleanup & structure enforcement:
python3 .agent/scripts/workspace-janitor.py --auto-clean --enforce-structure
```
