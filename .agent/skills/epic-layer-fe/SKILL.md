# Epic Layer FE (`/epic-layer-fe`)

Executes horizontal frontend UI architecture & reusable component design for an Epic:
1. Scans story `ui-spec.md` files in the epic directory.
2. Identifies matching patterns in `DESIGN.md` Section 5.
3. Scaffolds `layer-epic-fe.md` and maps registered UI component reuse.
